Tóm tắt bản thân

Sinh viên năm cuối ngành Công nghệ Thông tin (GPA 3.58/4.0), định hướng Lập trình viên Front-end với ReactJS. Thành thạo HTML5, CSS3, JavaScript (ES6+), chuyển đổi file thiết kế sang giao diện web chuẩn Responsive và tích hợp RESTful API với hệ thống Back-end. Đã tự thiết kế và triển khai hoàn chỉnh website thương mại điện tử Ros Watch Shop, kiểm thử cross-browser và tối ưu hiển thị trên nhiều thiết bị. Mong muốn gia nhập Alta Software để hỗ trợ nhóm chuyển đổi thiết kế sang giao diện chuẩn và tích hợp API, góp phần đẩy nhanh tiến độ hoàn thiện và bàn giao sản phẩm cho khách hàng.
